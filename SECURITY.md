# Security policy

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues.

Use GitHub's private vulnerability reporting feature for this repository if it is enabled. If it is not enabled, contact the repository owner privately through GitHub to arrange a secure report.

Include the affected component, steps to reproduce, and potential impact. Avoid sharing exploit details publicly until a fix is available.

## Supported versions

This project is under initial development. Supported versions will be listed here once releases are available.
